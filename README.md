# exam-answer-first-cn

一个面向中文应试的 Agent Skill:**先给能直接抄到试卷上的「答卷版答案」,再给展开解析**。

适用于让 AI 帮你做题、讲题、批改的场景,尤其针对中文理工科教材习题(自动控制原理、电路、模电、数电、信号与系统、电气控制、高等数学等)。

## 它解决什么问题

直接问 AI 做题,通常会得到一大段"讲解式"回答:有分析、有解释、有易错点,但**没法直接抄到卷面上**。这个 skill 把输出强制切成两段:

1. **一、答卷版答案** —— 只写能拿分的部分:小问分点、问内合句、公式独立成行、步骤自然提行、中间算术不写(那是草稿纸上的事)。
2. **二、解析** —— 为什么这样答、依据是什么、易错点、同类题通法,在这里随便展开。

## 核心规则

- **两段式输出契约**:顺序固定,不合并、不调换、不省略
- **多小问必须分点**:题目有 (1)(2)(3) 就按小问逐条作答(考卷上就是这么写的),只有同一个小问内部的多个要素才合句
- **按题型分三档**:原理题只给结论句;计算题按「公式 → 代入数值 → 结果」,结果带单位;证明题保留必要逻辑链
- **公式用 LaTeX**:行内 `$...$`、独立成行 `$$...$$`
- **图一律生成真图**:matplotlib 出图 + 本地静态服务,在对话里内联显示;不用 ASCII 字符硬拼框图
- **按需画图**:题目已把结构图、电路图作为已知条件给出时不要重画一遍
- 不编造教材页码、公式编号、题号、图号;图中连线读不清时明确说明,并给出条件性答案

## 安装

把整个目录放进 agent 的 skills 目录:

| Agent | skills 目录 |
|---|---|
| DSH (DeepSeek Harness) | `~/.dsh/skills/` |
| Claude Code | `~/.claude/skills/` |
| Codex | `~/.codex/skills/` |

## 依赖

绘图部分(可选,不画图也能工作)需要:

- Python 3 + matplotlib(中文字体建议 Microsoft YaHei 或 SimHei)
- 一个本地静态服务用于内联显示图片:

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory "$TEMP/dsh-figs"
```
